# обнови-БОЦ — перевыпуск приложения

Windows-приложение пересобирает основные приложения и установочные файлы.
Готовый CLI создаётся здесь:

```text
releases/tools/obnovi-boc-cli.exe
```

## Сборка CLI

Из корня проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-cli.ps1
```

Для чистой пересборки добавьте `-Clean`. Полученный EXE собран статически и не
требует Qt DLL, но для выполнения команд ему нужны каталог проекта и PowerShell.
Если программа находится внутри проекта, корень определяется автоматически.
Скрипт также создаёт отдельный архив `releases/obnovi-BOC-CLI-1.0.0.zip`.

## Операции

Запустите `releases/tools/obnovi-boc-cli.exe` двойным щелчком. Подготовка
конфигурации и сборка намеренно разделены:

- **1. Подготовить конфигурацию** — сканирует файлы прошивок и обновляет
  `app/config/device-catalog.json`;
- после этого конфигурацию можно проверить и отредактировать вручную;
- **2. Собрать приложение из готовых файлов** — выполняет чистую сборку внутренней
  и внешней редакций, не изменяя конфигурацию;
- **Собрать установщики из готовых файлов** — пересобирает обе редакции без
  изменения конфигурации, затем создаёт установщики и portable ZIP версии `1.0.0`.

Ход и результат операции отображаются в нижней части окна. Во время длительной
операции окно остаётся доступным, а закрытие блокируется до её завершения.
Корень проекта определяется автоматически.

## Команды CLI

Командная строка сохранена для автоматизации. Подготовить конфигурацию:

```powershell
.\releases\tools\obnovi-boc-cli.exe config
```

После проверки и ручного редактирования JSON чисто пересобрать обе редакции:

```powershell
.\releases\tools\obnovi-boc-cli.exe build
```

Пересобрать приложения и создать оба установщика версии `1.0.0`:

```powershell
.\releases\tools\obnovi-boc-cli.exe installer
```

Проверить, какой PowerShell-вызов будет выполнен, не запуская его:

```powershell
.\releases\tools\obnovi-boc-cli.exe installer --dry-run
```

Если EXE скопирован за пределы проекта, укажите корень явно:

```powershell
obnovi-boc-cli.exe build --root C:\path\to\burner
```

Команда возвращает код `0` при успехе, `1` при ошибке выполняемой операции и `2`
при неправильной командной строке или невозможности найти проект.
